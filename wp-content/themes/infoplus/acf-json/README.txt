ACF / Secure Custom Fields local JSON (see inc/setup.php for the load/save paths).

group_ip_home.json, group_ip_unternehmen.json, group_ip_kontakt.json, group_ip_faq.json
are generated by tools/build-acf-json.py in the repo root (not deployed). Do not edit
them by hand: change the builder, re-run it (python3 -I tools/build-acf-json.py) and
commit both. Every default_value is the old site's text; repeater, gallery and
relationship defaults are applied by the theme (inc/fields.php, inc/content.php).
The site settings group (group_ip_settings) is registered in PHP (inc/options.php).
