# Infoplus Webshop

WordPress + WooCommerce webshop for Infoplus Namensschilder (B2B nameplates). Built by Alture s.r.o.

| Folder | What | Deployed |
| --- | --- | --- |
| `wp-content/plugins/infoplus-suite/` | Infoplus Suite plugin: product configurator logic, editor link, orders, inquiry form, IFE sync | yes, as folder "Infoplus Suite" |
| `wp-content/themes/infoplus/` | Classic PHP theme that replaces Elementor | yes |
| `wp-content/mu-plugins/` | Theme preview helper | only if needed |
| `reference/` | Copies of InfoplusAPI and the two legacy plugins | no |
| `legacy/` | Export of the Elementor site (2026-10-20) | no |
| `docs/` | Plugin and theme documentation, commit maps | no |
| `tools/` | Field group builder, ZIP builder, catalog import pipeline | no |

Start with `CLAUDE.md` (project brief), then `docs/suite/PLUGIN-DOCUMENTATION.md` and `docs/theme/README.md`.

## Branches

- `main`: current line, on staging.
- `production`: the Suite as production runs it today.
- `feature/catalog-import`: catalog import (contained in `main`).
- Tags `archive/*`: retired branches.

## Deploy

1. Compare staging with the repo (files may have been changed over FTP).
2. `tools/build-zips.sh` writes `dist/infoplus-theme.zip` and `dist/infoplus-suite.zip`.
3. wp-admin: upload each ZIP with "Replace current with uploaded".
4. If field groups changed: Custom Fields > Field Groups > "Sync available". Never save these groups in the admin; they are generated by `tools/build-acf-json.py`.
